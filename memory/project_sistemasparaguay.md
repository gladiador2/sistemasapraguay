Empresa de desarrollo de software paraguaya. Landing page en reconstrucción.

**Productos:**
- **Fénix** = Facturación Electrónica Nacional Integrada y eXpress. Integrado con SIFEN (SET Paraguay). Sistema estrella.
- **Tu Primer Sistema** = POS gratuito con inventario, compras, ventas, reportes. Descarga en `descargas/tu-primer-sistema-setup.exe`.

**Servicios:** Apps móviles, páginas web, ecommerce, SaaS.

**Contacto:** WhatsApp +595 984 935 082
**Email (owner):** puertos-team@cba.com.py

**Paleta de identidad paraguaya:**
- Rojo: `#D52B1E` / oscuro `#A82015`
- Azul: `#0038A8` / oscuro `#00277A`
- Dorado: `#C8963E` (acento)
- Fondo: `#f7f7f9` (light) / `#1a1a1a` (dark)

**Archivos clave:**
- `index.html` = página original (preservada)
- `index-v2.html` = rediseño Apple-style con identidad paraguaya
- `apple-template/` = sistema de diseño reutilizable con Tailwind CSS

**Why:** El usuario quiere una landing con estética Apple (layout, animaciones, tipografía) pero con identidad paraguaya (bandera, colores rojo/azul/dorado).

**How to apply:** Usar la paleta paraguaya sobre el sistema de diseño Apple. Preservar siempre el `index.html` original y guardar nuevas versiones numeradas.
